## Linux Commands Used
- `sudo useradd` – Creates a new user account on the Linux system.
- `su` – Switches the current terminal session to another user account.
- `whoami` – Displays the username of the user currently logged into the terminal session.
- `pwd` – Prints the absolute path of the current working directory you are located in.
- `hostname` – Displays or sets the network name assigned to the system.
- `sudo` – Executes a single command with root or administrative privileges.
- `free` – Displays the total, used, and available system RAM and swap memory.
- `df` – Shows the available and used disk space on mounted file systems.
- `cat` – Reads and prints the contents of a text file directly into the terminal output.
- `uname` – Outputs core system and kernel details.
- `lscpu` – Displays detailed hardware specifications and architecture info of the system's CPU.
- `ls` – Lists all files and subdirectories stored inside the current directory.
- `mkdir` – Creates a new directory or folder inside the specified path.
- `cd` – Changes the terminal's active working directory to a target folder path.
- `touch` – Creates a new empty file, or updates the modification timestamp if the file already exists.
- `nano` – Opens a lightweight command-line text editor to view and edit files directly in the terminal.
