# Reflection

This lab was my first time really working inside a Linux environment, and it taught me a lot of basic but important skills.

I learned how to create a new user account and give it admin rights using `sudo`. At first I got a little confused switching between the root user and my new user, but after doing it a few times it started to make sense. I also learned simple commands to check where I am and what system I'm using, like `whoami`, `pwd`, and `hostname`. These seem small, but they are very useful for knowing your environment before doing anything else. Checking system information was interesting too. Commands like `uname -r`, `lscpu`, `free -h`, and `df -h` showed me details about the CPU, memory, and disk space that I never really thought about before. It made me realize how much information is available if you just know the right command to ask for it.

Making folders and files with `mkdir` and `touch` felt easy, but I did make a few mistakes along the way, like typos in folder names. It taught me to be more careful and to double check my commands before running them.

Lastly, building a GitHub repository and organizing my files properly showed me why version control and documentation matter. It's not just about doing the work, but also about keeping it organized so others (or even future me) can understand what was done.

Overall, this lab helped me feel more comfortable with Linux and gave me a good foundation for the more advanced topics coming up in this course, like Docker and Kubernetes.
