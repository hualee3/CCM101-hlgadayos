# Checkpoint 2 - Research: Security Best Practices 

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. It is important in cloud environments because it helps prevent unauthorized access and limits the damage if an account is compromised.

## Attack Surface

An attack surface refers to all the possible entry points that an attacker could use to access or exploit a virtual machine. These may include open network ports, running services, applications, and insecure configurations, so disabling unnecessary services helps reduce security risks.

## Default Deny Policy

It is safer to block all traffic by default because only authorized connections are allowed. This helps prevent unauthorized access, even from hackers whose identities are unknown because unauthorized connections are automatically denied, while only the services needed by the server are allowed.
