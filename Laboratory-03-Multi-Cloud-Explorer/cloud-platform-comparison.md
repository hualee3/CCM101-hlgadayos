# Cloud Platform Comparison

| Category                | AWS                                   | Microsoft Azure                        | Google Cloud Platform (GCP)                |
| ----------------------- | ------------------------------------- | -------------------------------------- | ------------------------------------------ |
| **Launch Year**         | 2006                                  | 2010                                   | 2008                                       |
| **Compute**             | Amazon EC2                            | Azure Virtual Machines                 | Compute Engine                             |
| **Storage**             | Amazon S3                             | Azure Blob Storage                     | Cloud Storage                              |
| **Networking**          | Amazon VPC                            | Azure Virtual Network                  | Virtual Private Cloud (VPC)                |
| **Identity**            | AWS IAM                               | Microsoft Entra ID                     | Cloud IAM                                  |
| **Primary Strength**    | Wide range of cloud services          | Works well with Microsoft products     | AI, data analytics, and Kubernetes         |
| **Ideal Organizations** | Startups, enterprises, and government | Organizations using Microsoft products | Companies doing AI or data work |

## Questions

**1. Which provider offers the broadest range of services?**
**AWS** offers the broadest range of cloud services. It started first, so it has had more time to build many tools for different needs.

**2. Which provider integrates best with Microsoft technologies?**
**Microsoft Azure** integrates best with Microsoft technologies. It works well with Windows Server, Microsoft 365, SQL Server, and Microsoft Entra ID, making it a good choice for organizations already using Microsoft products. 

**3. Which provider is strongest in AI and Kubernetes?**
**Google Cloud Platform (GCP)** is strong in AI and Kubernetes. Google also created Kubernetes, and Google is well known for AI research.

**4. Which platform would be chosen personally and why?**
I would choose **AWS** because it provides a wide range of cloud services and has a large global infrastructure. It can support different needs, such as computing, storage, networking, databases, and application development.
