# Google Cloud Platform

## Brief Overview
Google Cloud Platform (GCP) is Google's cloud computing platform. It provides services for computing, storage, networking, databases, AI, machine learning, data analytics, and application development. GCP was introduced in 2008 and uses Google's global infrastructure.

## Global Infrastructure
GCP has cloud infrastructure in many locations around the world. It is divided into Regions, which contain multiple data centers, Zones, which are locations within regions, and Google's Global Network, which connects data centers and cloud regions using fast networks. This helps provide fast and reliable cloud services.

## Cloud Management Console
The **Google Cloud Console** is the web-based interface used to create, manage, and monitor GCP resources. GCP also provides the **gcloud CLI**, **Cloud Shell** a browser-based terminal with built-in tools, and a mobile app for monitoring.

## Four (4) Core Services
1. **Compute Engine** – Provides virtual machines in the cloud.
2. **Cloud Storage** – object storage for unstructured data.
3. **Virtual Private Cloud (VPC)** – Creates secure virtual networks
4. **Cloud IAM** – Manages users and controls access to cloud resources.

## Three (3) Advantages
1. **Strongest Kubernetes support** – Google developed Kubernetes, and GCP is widely used for container-based applications.
2. **Strong AI and machine learning** – GCP provides strong tools for AI and machine learning.
3. **Good for Data Analytics** – GCP can be used to analyze large amounts of data.

## Typical Enterprise Use Cases
- Analyzing large amounts of data using BigQuery
- AI/ML model training and deployment
- Running applications using Kubernetes
- Streaming media and content using Google’s global network
