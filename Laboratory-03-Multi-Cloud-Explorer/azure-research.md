# Microsoft Azure 

## Brief Overview
Microsoft Azure is a cloud computing platform from Microsoft. It provides services for computing, storage, networking, databases, security, AI, and analytics. Azure works well with Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory.

## Global Infrastructure
Azure has data centers in different locations around the world. Its global infrastructure is divided into Regions, which contain data centers, Availability Zones, which help keep services running when one data center has a problem, and Region Pairs, which help with backup and recovery when a region has a major problem.

## Cloud Management Console
The **Azure Portal** is the primary web-based console for managing resources. Azure also provides **Azure CLI**, **Azure PowerShell**, and **Azure Cloud Shell** for scripting, along with a mobile app for monitoring.

## Four (4) Core Services
1. **Azure Virtual Machines** – Provides virtual servers for running applications and systems.
2. **Azure Blob Storage** – Stores unstructured data such as files, images, and backups
3. **Azure Virtual Network** – Creates secure virtual networks for Azure resources.
4. **Microsoft Entra ID** – Manages identities and access permissions

## Three (3) Advantages
1. **Microsoft Integration** – Works well with Microsoft products such as Windows Server, Microsoft 365, and Active Directory.
2. **Hybrid Cloud Support** – Connects local systems with Azure cloud services.
3. **Security and Identity Management** – Provides tools to protect resources and manage

## Typical Enterprise Use Cases
- Migrating on-premises Windows Server/AD environments to the cloud.
- Hybrid cloud deployments 
- Enterprise resource planning (ERP) and business applications 
- Building and managing software using GitHub or Azure DevOps
