# Mission Reflection

Among the three cloud platforms, **AWS impressed me the most** because it offers many cloud services and has a large global infrastructure. It can be used by startups, enterprises, and government organizations. AWS also provides services for computing, storage, networking, databases, security, and other needs.

AWS, Microsoft Azure, and Google Cloud Platform are similar because they all provide important cloud services such as **virtual machines, storage, networking, databases, identity management, and Kubernetes**. Even though the service names are different, they provide similar functions. For example, AWS uses Amazon EC2, Azure uses Azure Virtual Machines, and GCP uses Compute Engine for virtual machines. 

Business requirements are important when choosing a cloud platform because each provider has different strengths. **AWS** is a good choice for startups and businesses that need many cloud services. **Microsoft Azure** is good choice for organizations that already use Microsoft products. **GCP** is a good choice for projects involving AI, machine learning, data analytics, and Kubernetes. 

This activity taught me that a cloud consultant should understand the needs of an organization before recommending a cloud platform. It is important to look at the available services, cost, security, and business needs. A cloud consultant should also compare different platforms before making a recommendation. Different cloud platforms have different strengths, so the best platform depends on what the organization needs.

Lastly, this activity improved my **GitHub portfolio** because I was able to document my research, cloud comparisons, recommendations, and Linux investigation using Markdown files. It shows what I learned about AWS, Azure, GCP, and basic cloud services.
