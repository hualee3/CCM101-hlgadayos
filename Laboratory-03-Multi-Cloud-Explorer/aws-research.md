# Amazon Web Services (AWS)

## Brief Overview
Amazon Web Services (AWS) is a cloud computing platform launched by Amazon in 2006. It was one of the first major public cloud providers. AWS offers many cloud services, such as computing, storage, databases, networking, machine learning, and more. It is used by small businesses, large companies, and government organizations.

## Global Infrastructure
AWS has cloud infrastructure in many locations around the world, divided into Regions that contain several data centers, Availability Zones (AZs) that help keep services running if one location has a problem, and Edge Locations that bring content closer to users to make websites and applications load faster.

## Cloud Management Console
The **AWS Management Console** is a website used to create and manage AWS cloud services. AWS also provides the **AWS CLI** and **AWS CloudShell**, which allow commands and scripts to manage cloud resources.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – provides virtual computers or servers for running applications.
2. **Amazon S3 (Simple Storage Service)** – stores files, backups, images, and other data.
3. **Amazon RDS (Relational Database Service)** – provides managed databases such as MySQL and PostgreSQL.
4. **AWS IAM (Identity and Access Management)** – manages users and controls who can access AWS resources.

## Three (3) Advantages
1. **Scalabilty** – Resources can increase or decrease based on demand.
2. **Cost efficiency** – Pay only for the resources used.
3. **Global presence** – Provides cloud services through infrastructure around the world.

## Typical Enterprise Use Cases
- Hosting websites and mobile applications
- Storing and analyzing large amounts of data
- Backing up data and recovering lost data
- Machine learning and AI workloads
