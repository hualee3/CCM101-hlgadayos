# Checkpoint 2 - Research: The Language of Automation 

## 1. Bash Script

A Bash script is a file that contains Linux commands arranged to perform tasks automatically. The `#!/bin/bash` line, called the shebang, it tells the system to use the Bash shell to run the script.

## 2. Variables

Variables store information, such as folder paths, that a script can reuse. Using a variable like `$BACKUP_DIR` makes the script easier to update because the folder path can be changed in one place instead of changing it in several commands.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script at a specified time. It is essential in cloud operations because it automates repeated tasks, such as backups, and reduces the need for someone to run them manually.
